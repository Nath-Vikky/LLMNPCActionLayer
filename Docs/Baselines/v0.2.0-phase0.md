## Repeatable Checks

Clean the editor target:

```powershell
& "<UE_5.3>/Engine/Build/BatchFiles/Build.bat" LLMNPCDemoEditor Win64 Development -Project="<Project>/LLMNPCDemo.uproject" -WaitMutex -Clean
```

Build the editor target:

```powershell
& "<UE_5.3>/Engine/Build/BatchFiles/Build.bat" LLMNPCDemoEditor Win64 Development -Project="<Project>/LLMNPCDemo.uproject" -WaitMutex
```

Run the Phase 0 automation tests:

```powershell
& "<UE_5.3>/Engine/Binaries/Win64/UnrealEditor-Cmd.exe" "<Project>/LLMNPCDemo.uproject" -unattended -nop4 -nosplash -NullRHI '-ExecCmds=Automation RunTests LLMNPCActionLayer.Phase0; Quit' '-TestExit=Automation Test Queue Empty' -log
```
